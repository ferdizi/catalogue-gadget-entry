# THE ANTI-GRAVITY TEAPOT

A catalogue photograph of an impossible gadget: a white porcelain teapot
that pours its tea **upward**, in a golden arc, into a small cup floating
above it.

`main.py` (Python 3.13, standard library only) draws the whole studio
product shot in code — porcelain body, lid and knob, spout, handle, the
upward tea arc with droplets, and the floating cup — and writes it to
`/output/entry.png` (1024×1024 PNG).

Run it:

```sh
python3 main.py
```
